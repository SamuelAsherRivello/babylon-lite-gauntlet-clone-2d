# Proposal

## Why
Deliver the requested playable cooperative dungeon experience with a independently verifiable sprite-rendering system.

## What Changes
- Create original Blender orthographic miniature sprites for eight actors and dungeon props. Render tile-based 2D action with Babylon Lite WebGPU; preserve transparent silhouettes and player color rings/numbers. Responsive camera, floor/walls, projectiles and readable effects. Unsupported GPU shows useful recovery.
